# Core compatibility

[한국어](core-compatibility.ko.md)

The HWP package declares `engines.soksak: "^0.0.41"`, which admits core 0.0.41 and every later 0.0 release ([versions and ranges](https://github.com/soksak-app/core/blob/main/docs/spec/installation.md#versions-and-ranges)). The package requires 0.0.41 because `events.json` declares the `surface` that 0.0.41 adds to each view record. The package names no release of the plugin API and declares no dependency on it: the application resolves `@soksak/plugin-api` and its subpaths for the page through the import map of the view, and the tests resolve the same specifiers to the fixture of `test/fixtures/plugin-api/`. 0.0.40 is the version of the core release of F502-13 (F502-13-1), the first core release that accepts `exposes.element`, which `plugin.json` declares; core 0.0.39 and earlier accept only the exposes kinds `status`, `commands` and `dom`, so they refuse it. Its `plugin.json` also declares a view composition without `surface.module`, which core releases from `0.0.24` accept.
