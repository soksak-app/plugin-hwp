# Core compatibility

[English](core-compatibility.md)

HWP package는 `engines.soksak: "^0.0.34"`를 선언한다. 이 범위는 core version-range 규칙에 따라 core release `0.0.34`를 허용하고, 이전 version 및 검증하지 않은 이후 version과의 호환성을 주장하지 않는다. Core `0.0.34`는 `surface.module` 없는 view composition을 가진 이 package의 `plugin.json`을 받는다.
